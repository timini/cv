\section{Applied AI Projects}

\textbf{Rewire Bio} {\color{muted}\small biological AI benchmark database} \hfill {\small\href{https://benchmarks.rewirebio.io}{\color{accent}benchmarks.rewirebio.io}}\par
Helps researchers choose the right AI model for a biological task. Search by biological question across omics and molecular biology, compare models on published benchmarks, and trace every result to its source paper or run. Agents can query it and rerun benchmarks through an MCP server and a Claude Code plugin.
\gap

\textbf{Agentic Verification} {\color{muted}\small Claude Code plugin, GitHub Action, research paper} \hfill {\small\href{https://github.com/timini/agentic-verification}{\color{accent}github.com/timini/agentic-verification}}\par
Checks that the tests an AI coding agent writes would actually catch bugs. It plants small bugs in the code the agent changed, and the agent keeps writing tests until every one is caught. In a published study on real changes to 8 open-source Python libraries, agents using it caught \textbf{99\%} of planted bugs, against 92\% without it.
\gap

\textbf{neuromem} {\color{muted}\small agent memory library} \hfill {\small\href{https://github.com/timini/neuromem}{\color{accent}github.com/timini/neuromem}}\par
Long-term memory for LLM agents, modelled on how the brain moves memories from the hippocampus to the neocortex. Works with Claude, OpenAI, Gemini and local models. Scores \textbf{0.870} on the LongMemEval-s benchmark (n=100), above the published EmergenceMem baseline of 0.86.
\gap

\textbf{drill-me} {\color{muted}\small Claude Code plugin} \hfill {\small\href{https://github.com/timini/drill-me}{\color{accent}github.com/timini/drill-me}}\par
Turns Claude into a tutor: it quizzes you before it explains, schedules reviews on a forgetting curve, and remembers your weak spots across sessions.
