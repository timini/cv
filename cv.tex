\section{Selected Open Source}

\textbf{Agentic Verification} \hfill {\small\href{https://github.com/timini/agentic-verification}{\color{accent}github.com/timini/agentic-verification}}\par
Claude Code plugin and GitHub Action that checks whether tests catch broken code by running every mutant of the lines a change touches. Backed by a pre-registered study and agent benchmarks on 8 open-source Python libraries, published as a paper. On 14 real commits, the agent's tests caught 99\% of mutants with the plugin against 92\% without.
\gap

\textbf{drill-me} \hfill {\small\href{https://github.com/timini/drill-me}{\color{accent}github.com/timini/drill-me}}\par
Claude Code plugin that turns Claude into an adaptive tutor: it quizzes before it explains, schedules reviews with spaced repetition and remembers what you got wrong across sessions.
\gap

\textbf{neuromem} \hfill {\small\href{https://github.com/timini/neuromem}{\color{accent}github.com/timini/neuromem}}\par
Long-term memory for LLM agents modelled on hippocampal consolidation, with providers for Gemini, OpenAI, Claude and local models. Scores 0.870 on the LongMemEval-s benchmark (n=100).
